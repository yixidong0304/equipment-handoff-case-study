# Equipment handoff case study

Static portfolio page for “Reporting an Equipment Issue: From Observation to Maintenance Handoff.”

The page is a foundation only: six sections, shared styles, and labeled asset placeholders. Section narratives are not drafted. The navy, mint, and sage colors are portfolio design choices, not the verified course palette.

## Preview

From this folder:

```bash
python3 -m http.server 8765 --bind 127.0.0.1
```

Open http://127.0.0.1:8765/

Python 3 is already available on this machine, so no packages are required.

## Files

- `index.html` — page structure
- `styles.css` — visual system
- `nav.js` — section tracking and sidebar collapse
- `assets/` — images and recordings, when they are ready
- `docs/build-progress.md` — build status and the asset list
